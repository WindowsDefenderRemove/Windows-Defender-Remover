## Service & Exclusion Controls
- **Live Scanner Toggle**: Suspends `WinDefend`, `Sense`, and `WdNisSvc` cleanly during local compiler or lab runs.
- **SmartScreen Filter**: Silences unsigned binary warnings without breaking network connectivity.
- **PowerShell Rules**: Export clean `Add-MpPreference` exclusion scripts from `ps/`.

## Restoring Default Protection
Run the tray utility as Administrator and click **Restore Defaults** to re-register all Defender services immediately.
